# CodeLab II - Skills Portfolio (Assessment 1)

Three Python and Tkinter programs, each in its own folder.

| Exercise | Folder              | What it is                                                                                   |
| -------- | ------------------- | -------------------------------------------------------------------------------------------- |
| 1        | `01-MathsQuiz`      | A 10-question addition and subtraction quiz with three difficulty levels, scoring and a rank |
| 2        | `02-AlexaJokes`     | A joke-telling app that reads `randomJokes.txt`, with narration, music and a laugh sound     |
| 3        | `03-StudentManager` | A student marks manager: a basic version and an extension version that edits the data file   |

## How to run

1. Install Python 3 (I used 3.13) and the libraries:
   ```
   pip install -r requirements.txt
   ```
2. Open a terminal in an exercise folder and run its program, for example:
   ```
   cd "01-MathsQuiz"
   python maths_quiz.py
   ```
   Each exercise folder has its own README with the exact steps.
